第一章 原子结构与性质

第一节 原子结构

一、能层与能级

1. 能层

根据核外电子的能量不同，将核外电子分为不同的能层（电子层），用K、L、M、N、O、P、Q表示，能量依次升高。-23

2. 能级

同一能层里电子的能量也可能不同，又将其分成不同的能级，通常用s、p、d、f表示。-23

各能层的能级分布及最多电子数：

能层符号能级最多电子数
一K1s2
二L2s 2p2+6=8
三M3s 3p 3d2+6+10=18
四N4s 4p 4d 4f2+6+10+14=32

3. 能层与能级的关系

  • 第一能层（K）只有s能级

  • 第二能层（L）有s、p两种能级，p能级上有三个原子轨道px、py、pz，它们具有相同的能量

  • 第三能层（M）有s、p、d三种能级

二、电子云与原子轨道

1. 电子云

由于核外电子的概率密度分布看起来像一片云雾，因而被形象地称为电子云。电子云轮廓图称为原子轨道。-23

2. 原子轨道

  • s电子云轮廓图呈球形

  • p电子云轮廓图呈哑铃形，有px、py、pz三种取向

  • d电子云有五种取向

  • f电子云有七种取向

三、基态原子的核外电子排布

1. 构造原理

电子尽可能地先占有能量低的轨道，然后进入能量高的轨道，使整个原子的能量处于最低状态。基态原子核外电子在原子轨道上的排布顺序为：

1s→2s→2p→3s→3p→4s→3d→4p→5s→4d→5p→6s→4f→5d→6p→7s……

2. 核外电子排布的三条规则

（1）能量最低原理：电子优先占据能量最低的轨道。

（2）泡利原理：每个原子轨道里最多只能容纳2个电子，且自旋状态相反。

（3）洪特规则：当电子排布在同一能级的不同轨道时，基态原子中的电子总是优先单独占据一个轨道，且自旋状态相同。-23

特别提醒——洪特规则特例：

当能量相同的原子轨道在全满（p⁶、d¹⁰、f¹⁴）、半满（p³、d⁵、f⁷）、全空（p⁰、d⁰、f⁰）状态时，原子的能量最低。

典型例子：

  • ₂₄Cr的电子排布式为[Ar]3d⁵4s¹（而非[Ar]3d⁴4s²）

  • ₂₉Cu的电子排布式为[Ar]3d¹⁰4s¹（而非[Ar]3d⁹4s²）-23

四、电子的跃迁与原子光谱

1. 基态与激发态

  • 基态原子：处于最低能量状态的原子

  • 激发态原子：基态原子吸收能量后，电子跃迁到较高能级

2. 原子光谱

不同元素的原子发生跃迁时会吸收或释放不同的光，可以用光谱仪摄取各种元素的电子的吸收光谱或发射光谱，总称原子光谱。

  • 吸收光谱：背景亮，光谱暗

  • 发射光谱：背景暗，光谱亮

特别提醒：焰色反应是电子跃迁的结果，金属的焰色反应是物理变化过程，不属于化学变化。-23

五、重难点突破

重难点1：能级交错现象

构造原理中出现了能级交错现象，即4s能级的能量低于3d能级。这是因为当考虑多电子原子时，电子之间的相互作用使得某些能级的能量顺序发生变化。例如：

  • E(4s) < E(3d)

  • E(5s) < E(4d)

  • E(6s) < E(4f) < E(5d)

重难点2：电子排布式的书写要点

  1. 在书写电子排布式时，一般情况下，能层低的能级要写在左边，而不是按构造原理的顺序写。例如：₁₆S的电子排布式应写成1s²2s²2p⁶3s²3p⁴。-

  2. 在得出构造原理之前，由原子光谱得知有些过渡金属元素基态原子电子排布不符合构造原理（如Cr和Cu）。-

  3. 在多电子的原子中，电子最后填入的能级不一定是原子最外能层上的能级，如Ti、V等过渡元素电子最后填入的是3d能级。-

七、典型例题

例1：写出₂₄Cr和₂₉Cu的基态原子电子排布式。

解析：

  • ₂₄Cr：1s²2s²2p⁶3s²3p⁶3d⁵4s¹（或[Ar]3d⁵4s¹）

二、元素周期律

1. 原子半径的变化规律

  • 同周期从左到右：原子半径逐渐减小

  • 同主族从上到下：原子半径逐渐增大

  • 稀有气体原子半径通常不参与比较（测定方法不同）

2. 电离能

（1）第一电离能：气态电中性基态原子失去一个电子转化为气态基态正离子所需的最低能量。

变化规律：

  • 同周期从左到右：总体呈增大趋势

  • 同主族从上到下：逐渐减小

  • 异常：ⅡA > ⅢA（ns²全满更稳定），ⅤA > ⅥA（np³半满更稳定）

（2）逐级电离能

同一元素的逐级电离能逐渐增大。当电离能发生突变时，说明电子从不同能层失去，可用来判断元素的化合价。

3. 电负性

（1）定义：元素的原子在分子中吸引共用电子对的能力。

（2）变化规律：

  • 同周期从左到右：电负性逐渐增大

  • 同主族从上到下：电负性逐渐减小

  • 金属元素的电负性一般小于1.8，非金属元素一般大于1.8

（3）应用：

  • 判断元素的金属性和非金属性

  • 判断化学键的类型（电负性差值>1.7通常为离子键，<1.7通常为共价键）

  • 判断元素在化合物中的化合价

4. 金属性与非金属性

三、重难点突破

重难点1：第一电离能的异常现象

同周期中，ⅡA族和ⅤA族的第一电离能分别高于相邻的ⅢA族和ⅥA族。原因：

  • ⅡA族：价电子排布为ns²（全满），较稳定，不易失电子

  • ⅤA族：价电子排布为ns²np³（半满），较稳定，不易失电子

重难点2：元素周期律的综合应用

利用元素在周期表中的位置（周期、族）→ 推断原子结构（电子排布）→ 推断元素性质（金属性、非金属性、电离能、电负性等），形成“位—构—性”的思维链条。

五、典型例题

例2：比较Na、Mg、Al的第一电离能大小，并解释原因。

解析：I₁(Na) < I₁(Al) < I₁(Mg)

原因：Na、Mg、Al的价电子排布分别为3s¹、3s²、3s²3p¹。Mg的3s²为全满状态，较稳定，第一电离能最大。Al的3p¹电子能量较高，容易失去，第一电离能较小。Na的3s¹电子最容易失去，第一电离能最小。

第二章 分子结构与性质

第一节 共价键

一、共价键的形成

1. 共价键的本质

共价键的本质是原子间通过共用电子对（电子云重叠）而形成的相互作用。两个原子各自提供一个自旋方向相反的未成对电子，在核间形成电子云密度较大的区域，将两个原子核吸引在一起。

2. 共价键的形成条件

  • 两原子各有一个未成对电子，且自旋方向相反

  • 原子轨道能量相近、对称性匹配、最大重叠

二、共价键的类型

1. σ键与π键

类型形成方式特点示例
σ键原子轨道“头碰头”重叠可绕键轴旋转，重叠程度大，键能大H-H、C-H
π键原子轨道“肩并肩”重叠不能绕键轴旋转，重叠程度小，键能较小C=C中的第二键

规律：单键全是σ键；双键中有1个σ键和1个π键；三键中有1个σ键和2个π键。-50

2. 极性键与非极性键

类型形成条件示例
非极性键同种元素原子间形成H-H、Cl-Cl
极性键不同种元素原子间形成H-Cl、C-O

三、键参数

1. 键能

气态基态原子形成1mol化学键释放的最低能量（或断开1mol化学键所需的最低能量）。

  • 键能越大，化学键越牢固

  • 可用于计算化学反应的反应热：ΔH = 反应物键能总和 - 生成物键能总和

2. 键长

形成共价键的两个原子之间的核间距。

  • 键长越短，键能越大，化学键越牢固

  • 同种原子形成的键，键长越短，键能越大

3. 键角

在多原子分子中，两个相邻共价键之间的夹角称为键角。键角是决定物质分子空间结构的主要因素之一。-27

四、重难点突破

重难点1：σ键与π键的识别

判断方法：

  • 单键 → 1个σ键

  • 双键 → 1个σ键 + 1个π键

  • 三键 → 1个σ键 + 2个π键

注意：σ键数目 = 中心原子形成的共价键数（包括单键和多重键中的σ键）；π键数目 = 双键数 + 2×三键数。

重难点2：键角大小的比较

影响键角大小的因素主要有三个：一是中心原子的杂化轨道类型；二是中心原子的孤电子对数；三是中心原子的电负性大小。-27

（1）杂化方式不同：sp杂化 > sp²杂化 > sp³杂化。例如键角：CH≡CH > CH₂=CH₂ > CH₄。-27

（2）杂化方式相同，孤电子对数不同：由于斥力大小顺序为“孤电子对-孤电子对 > 孤电子对-成键电子对 > 成键电子对-成键电子对”，孤电子对数越多，键角越小。例如键角：CH₄ > NH₃ > H₂O。-27

（3）杂化方式相同且孤电子对数目也相同：利用中心原子的电负性大小比较。例如H₂O和H₂S中，中心原子均为sp³杂化，分子空间结构均为V形。由于电负性O>S，H₂O中成键电子对间的斥力更大，键角H₂O（105°）> H₂S（92.1°）。-27

（4）同一粒子中不同共价键的键角：由于斥力“双键间 > 双键与单键间 > 单键间”，键角大小不同。如甲醛分子中，∠H-C=O > ∠H-C-H。-27

第二节 分子的空间结构

一、分子结构的测定

1. 红外光谱

分子中的原子不是固定不动的，而是不断地振动的。当一束红外线透过分子时，分子会吸收跟它的某些化学键的振动频率相同的红外线，再记录到图谱上呈现吸收峰。可分析出分子中含有何种化学键或官能团的信息。-28

现代化学常利用质谱仪测定分子的相对分子质量。-28

三、价层电子对互斥模型（VSEPR）

1. 基本内容

价层电子对互斥模型认为，分子的空间结构是中心原子周围的价层电子对相互排斥的结果。价层电子对是指分子中的中心原子与结合原子间的σ键电子对和中心原子上的孤电子对。多重键只计其中的σ键电子对，不计π电子对。-28

2. 价层电子对数的确定

价层电子对数 = σ键电子对数 + 孤电子对数

（1）σ键电子对数：中心原子形成几个σ键，就有几对σ键电子对。

（2）孤电子对数：孤电子对数 = (a - xb) / 2

  • a = 中心原子的价电子数

    • 主族元素：a = 最外层电子数

    • 阳离子：a = 价电子数 - 离子电荷数

    • 阴离子：a = 价电子数 + |离子电荷数|

  • x = 与中心原子结合的原子数

  • b = 与中心原子结合的原子最多能接受的电子数（H为1，其他原子为8-该原子的价电子数）

-28

四、杂化轨道理论

1. 基本内容

在形成分子时，中心原子的若干能量相近的原子轨道重新组合，形成一组新的原子轨道——杂化轨道。杂化轨道的数目等于参与杂化的原子轨道数目。

2. 杂化类型与空间构型

杂化类型参与杂化的轨道杂化轨道数空间构型键角示例
sp1个s + 1个p2直线形180°BeCl₂、C₂H₂
sp²1个s + 2个p3平面三角形120°BF₃、C₂H₄
sp³1个s + 3个p4四面体形109°28′CH₄、NH₃、H₂O

3. 杂化类型的判断方法

  • 价层电子对数 = 2 → sp杂化

  • 价层电子对数 = 3 → sp²杂化

  • 价层电子对数 = 4 → sp³杂化

注意：杂化轨道数 = 价层电子对数，但VSEPR模型与分子空间结构可能不同（当存在孤电子对时）。

五、重难点突破

重难点1：VSEPR模型与分子空间结构的区分

VSEPR模型考虑了孤电子对，而分子空间结构不考虑孤电子对（孤电子对不可见）。例如：

  • H₂O：价层电子对数=4 → VSEPR模型为四面体形 → 略去2对孤电子 → 分子空间结构为V形

  • NH₃：价层电子对数=4 → VSEPR模型为四面体形 → 略去1对孤电子 → 分子空间结构为三角锥形

重难点2：等电子体原理

原子数和价电子数相同的微粒互为等电子体，互为等电子体的微粒具有相似的结构。-50

例如：CO₂、N₂O、NO₂⁺、N₃⁻互为等电子体，均为直线形。

重难点3：杂化轨道与分子性质的关系

  • sp杂化 → 直线形 → 键角180°

  • sp²杂化 → 平面三角形 → 键角120°

  • sp³杂化 → 四面体形 → 键角109°28′

例4：利用VSEPR理论判断SO₃、SO₃²⁻、NH₄⁺的空间结构。

第三节 分子结构与物质的性质

一、共价键的极性

1. 键的极性

类型形成条件电子对偏移示例
极性键不同种元素原子间偏向电负性大的原子H-Cl
非极性键同种元素原子间不偏移H-H

2. 分子的极性

类型条件示例
非极性分子正负电荷中心重合H₂、CO₂、CH₄、BF₃
极性分子正负电荷中心不重合HCl、H₂O、NH₃

判断方法：

  • 双原子分子：键的极性 = 分子的极性

  • 多原子分子：取决于键的极性和分子的空间结构是否对称

二、分子间作用力

1. 范德华力

存在于充分接近的分子间的一种作用力，比化学键弱得多，无饱和性和方向性。影响范德华力的因素包括分子的极性和相对分子质量等。-

  • 组成和结构相似的分子，相对分子质量越大，范德华力越大

  • 分子极性越大，范德华力越大

2. 氢键

由已经与电负性很大的原子（N、O、F）形成共价键的氢原子与另一个电负性很大的原子形成的一种作用力。-

表示方法：X-H···Y（X、Y为N、O、F等电负性大的原子）

特点：

  • 氢键是一种特殊的分子间作用力，不属于化学键

  • 具有方向性和饱和性

  • 强度：共价键 > 氢键 > 范德华力-

分类：

  • 分子间氢键：使熔沸点升高（如H₂O、HF、NH₃）

  • 分子内氢键：使熔沸点降低（如邻羟基苯甲醛）

三、分子的手性

1. 手性分子

互为镜像且不能重叠的分子称为手性分子。

2. 手性碳原子

连接四个不同基团的碳原子称为手性碳原子（不对称碳原子）。

四、重难点突破

重难点1：分子极性的判断

判断步骤：

  1. 判断键的极性（同种元素为非极性键，不同种元素为极性键）

  2. 判断分子的空间结构是否对称

  3. 若结构对称且键有极性 → 非极性分子；若结构不对称 → 极性分子

重难点2：氢键对物质性质的影响

  • 分子间氢键 → 熔沸点升高（如H₂O的沸点远高于H₂S）

  • 分子内氢键 → 熔沸点降低（如邻羟基苯甲醛的沸点低于对羟基苯甲醛）

  • 氢键影响物质的溶解性（如NH₃极易溶于水）

重难点3：范德华力与氢键的比较

比较项范德华力氢键
强度较弱较强（但仍远弱于化学键）
饱和性无有
方向性无有
对熔沸点的影响相对分子质量越大，熔沸点越高分子间氢键使熔沸点升高

五、易错辨析

错误认知正确理解
含有极性键的分子一定是极性分子CO₂含有极性键但是非极性分子
氢键是化学键氢键是分子间作用力，不是化学键
分子内氢键使熔沸点升高分子内氢键使熔沸点降低
范德华力有饱和性和方向性范德华力无饱和性和方向性

六、典型例题

例5：比较H₂O、H₂S、H₂Se的沸点高低，并解释原因。

解析：沸点：H₂O > H₂Se > H₂S

原因：H₂O分子间存在氢键，使沸点显著升高。H₂S和H₂Se分子间只有范德华力，且H₂Se的相对分子质量大于H₂S，范德华力更大，所以H₂Se的沸点高于H₂S。

第三章 晶体结构与性质

第一节 物质的聚集状态与晶体的常识

一、物质的聚集状态

1. 三种基本聚集状态

状态微粒排列微粒运动宏观特征
气态无序自由运动无固定形状和体积
液态近程有序可流动有固定体积，无固定形状
固态有序振动有固定形状和体积

2. 其他聚集状态

  • 等离子体：由离子和电子组成，存在于霓虹灯、闪电等中

  • 液晶：介于液态和晶态之间，具有各向异性

二、晶体与非晶体

1. 晶体的特征

  • 自范性：在适宜条件下晶体能够自发地呈现规则的多面体几何外形

  • 各向异性：晶体在不同方向上物理性质不同

  • 对称性：晶体具有特定的对称性

  • 固定的熔点：晶体有固定的熔点

2. 晶体与非晶体的区别

比较项晶体非晶体
微粒排列有序无序
自范性有无
各向异性有无（各向同性）
熔点固定不固定
X射线衍射有明锐衍射峰无明锐衍射峰

判断晶体与非晶体最可靠的方法：X射线衍射实验。-37

三、晶胞

1. 定义

晶胞是描述晶体结构的基本单元，是晶体中最小的重复单元。

2. 晶胞中微粒数目的计算——均摊法

位置贡献
顶点1/8
棱上1/4
面上1/2
体内1

3. 晶胞参数与密度计算

密度公式：ρ = Z·M / (Nₐ·V)

其中：

  • Z = 一个晶胞中含有的微粒数

  • M = 摩尔质量（g/mol）

  • Nₐ = 阿伏加德罗常数

  • V = 晶胞体积（cm³）

对于立方晶胞：V = a³（a为棱长，注意单位换算：1 nm = 10⁻⁷ cm，1 pm = 10⁻¹⁰ cm）-

四、重难点突破

重难点1：均摊法的应用

计算晶胞中微粒数目时，根据不同位置微粒的贡献率进行计算。例如NaCl晶胞：

  • Na⁺：12个棱上（×1/4）+ 1个体内 = 12×1/4 + 1 = 4

  • Cl⁻：8个顶点（×1/8）+ 6个面上（×1/2）= 8×1/8 + 6×1/2 = 4

所以NaCl晶胞中含有4个Na⁺和4个Cl⁻。

重难点2：晶胞密度的计算

注意单位的统一：

  • 晶胞参数a若为pm，需换算为cm（1 pm = 10⁻¹⁰ cm）

  • 密度单位通常为g·cm⁻³

五、典型例题

例6：已知某晶体的晶胞为面心立方，晶胞参数a = 400 pm，晶体的摩尔质量为M g/mol，求该晶体的密度。

解析：

  • 面心立方晶胞中微粒数：8×1/8 + 6×1/2 = 4

  • 晶胞质量：m = 4M / Nₐ

  • 晶胞体积：V = (400×10⁻¹⁰ cm)³ = 6.4×10⁻²³ cm³

  • 密度：ρ = 4M / (Nₐ × 6.4×10⁻²³) g·cm⁻³

第二节 分子晶体与共价晶体

一、分子晶体

1. 定义

分子间以分子间作用力（范德华力或氢键）相结合的晶体。

2. 构成微粒

分子

3. 微粒间作用力

分子间作用力（范德华力、氢键）；分子内为共价键

4. 典型物质

  • 所有非金属氢化物（H₂O、NH₃、HCl等）

  • 部分非金属单质（卤素、O₂、N₂、P₄等）

  • 部分非金属氧化物（CO₂、SO₂等）

  • 酸（H₂SO₄、HNO₃等）

  • 大多数有机物

5. 性质特点

  • 熔沸点较低

  • 硬度较小

  • 不导电（部分溶于水后导电）

二、共价晶体（原子晶体）

1. 定义

相邻原子间以共价键相结合而形成空间网状结构的晶体。

2. 构成微粒

原子

3. 微粒间作用力

共价键

4. 典型物质

金刚石、晶体硅、SiO₂、SiC、BN等

5. 性质特点

  • 熔沸点很高

  • 硬度很大

  • 不导电（晶体硅为半导体）

三、分子晶体与共价晶体的比较

比较项分子晶体共价晶体
构成微粒分子原子
微粒间作用力分子间作用力共价键
熔沸点低高
硬度小大
导电性不导电一般不导电
典型实例干冰、冰金刚石、SiO₂

四、重难点突破

重难点1：分子晶体熔沸点的比较

  • 分子间作用力越大，熔沸点越高

  • 含有氢键的分子晶体熔沸点较高

  • 组成和结构相似的分子晶体，相对分子质量越大，范德华力越大，熔沸点越高

重难点2：共价晶体熔沸点的比较

  • 共价键键能越大，熔沸点越高

  • 键长越短，键能越大，熔沸点越高

  • 例如：金刚石（C-C）> 晶体硅（Si-Si）

五、典型例题

例7：比较金刚石、晶体硅、SiO₂的熔沸点高低，并解释原因。

解析：熔沸点：金刚石 > SiO₂ > 晶体硅

原因：三者均为共价晶体，熔沸点取决于共价键的键能。C-C键的键长最短，键能最大，所以金刚石的熔沸点最高。Si-O键的键能大于Si-Si键，所以SiO₂的熔沸点高于晶体硅。

第三节 金属晶体与离子晶体

一、金属键与金属晶体

1. 金属键

金属原子脱落下来的价电子形成遍布整块晶体的“电子气”，被所有原子共用，从而把所有金属原子维系在一起。-37

2. 金属晶体的性质

  • 导电性：自由电子在电场作用下定向移动

  • 导热性：自由电子传递热量

  • 延展性：金属原子层间滑动，金属键不被破坏

  • 金属光泽：自由电子吸收和反射光

3. 金属晶体的堆积方式

堆积方式配位数空间利用率示例
简单立方652%Po
体心立方868%Na、K、Fe
面心立方1274%Cu、Ag、Au
六方最密堆积1274%Mg、Zn

二、离子晶体

1. 定义

由阳离子和阴离子通过离子键结合而成的晶体。

2. 构成微粒

阳离子和阴离子

3. 微粒间作用力

离子键

4. 典型物质

NaCl、CsCl、CaF₂、MgO等

5. 晶格能

气态离子形成1mol离子晶体释放的能量。

  • 离子电荷越大，晶格能越大

  • 离子半径越小，晶格能越大

  • 晶格能越大，离子晶体的熔沸点越高，硬度越大

三、重难点突破

重难点1：离子晶体的配位数

晶体阳离子配位数阴离子配位数结构类型
NaCl66面心立方
CsCl88体心立方
CaF₂84萤石型

重难点2：晶格能与离子晶体性质的关系

晶格能越大 → 离子键越强 → 熔沸点越高、硬度越大

例如：MgO的晶格能大于NaCl（Mg²⁺和O²⁻的电荷数大于Na⁺和Cl⁻），所以MgO的熔点（2852°C）远高于NaCl（801°C）。

四、典型例题

例8：比较NaCl、KCl、MgO的熔点高低，并解释原因。

解析：熔点：MgO > NaCl > KCl

原因：MgO中离子电荷为+2和-2，而NaCl和KCl中离子电荷为+1和-1。MgO的晶格能远大于NaCl和KCl，所以MgO的熔点最高。Na⁺的半径小于K⁺，NaCl的晶格能大于KCl，所以NaCl的熔点高于KCl。

第四节 配合物与超分子

一、配位键

1. 定义

由一方提供孤电子对，另一方提供空轨道而形成的化学键。这类“电子对给予-接受”键被称为配位键。提供空轨道的原子或离子称为中心原子或离子，提供孤电子对的原子或离子称为配体。-

2. 表示方法

用“→”表示，箭头从提供孤电子对的原子指向提供空轨道的原子。

二、配合物

1. 定义

由中心原子（或离子）和配体以配位键结合而成的化合物。

2. 组成

  • 中心原子（或离子） ：通常是过渡金属的原子或离子（如Fe³⁺、Cu²⁺、Ag⁺等）

  • 配体：提供孤电子对的分子或离子（如H₂O、NH₃、Cl⁻、CN⁻等）

  • 配位数：直接与中心原子（或离子）形成配位键的配体数目

3. 典型配合物

  • [Cu(H₂O)₄]²⁺：蓝色

  • [Cu(NH₃)₄]²⁺：深蓝色

  • [Fe(SCN)]²⁺：血红色

  • [Ag(NH₃)₂]⁺：无色

三、超分子

1. 定义

由两种或两种以上的分子通过分子间作用力（如氢键）结合而成的复杂有序的分子聚集体。

2. 特征

  • 分子间通过非共价键结合

  • 具有自组装能力

  • 具有选择性识别能力

3. 典型实例

  • 冠醚：识别碱金属离子

  • 杯酚：识别C₆₀和C₇₀

  • DNA双螺旋结构

四、重难点突破

重难点1：配位键与共价键的区别

比较项配位键普通共价键
电子来源一方提供孤电子对，另一方提供空轨道双方各提供一个电子
形成后与普通共价键完全相同与普通共价键完全相同
表示方法用“→”表示用“—”表示

重难点2：配位化合物的命名

命名顺序：配体数 + 配体名称 + “合” + 中心原子名称 + （中心原子氧化态）

例如：[Cu(NH₃)₄]SO₄ —— 硫酸四氨合铜(II)

五、典型例题

例9：解释为什么向CuSO₄溶液中加入过量氨水，溶液颜色由蓝色变为深蓝色。

解析：CuSO₄溶液中存在[Cu(H₂O)₄]²⁺（蓝色）。加入过量氨水后，NH₃分子中的氮原子提供孤电子对，Cu²⁺提供空轨道，形成[Cu(NH₃)₄]²⁺（深蓝色）。配体H₂O被NH₃取代，形成了更稳定的配合物。

  • 构造原理顺序：1s→2s→2p→3s→3p→4s→3d→4p→5s→4d→5p→6s→4f→5d→6p→7s

  • 洪特规则特例：全满（d¹⁰）、半满（d⁵）更稳定

2. 元素周期律

  • 同周期从左到右：原子半径减小，电负性增大，第一电离能增大（有异常），金属性减弱，非金属性增强

  • 同主族从上到下：原子半径增大，电负性减小，第一电离能减小，金属性增强，非金属性减弱

3. 分子空间结构判断

  • 价层电子对数=2 → 直线形（sp）

  • 价层电子对数=3 → 平面三角形（sp²）

  • 价层电子对数=4 → 四面体形（sp³）

4. 晶体类型与性质

  • 共价晶体 > 离子晶体 > 分子晶体（熔沸点、硬度）

  • 离子晶体中晶格能越大，熔沸点越高

  • 分子晶体中含有氢键的熔沸点较高
